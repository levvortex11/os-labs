Вихарев Лев Александрович, М8О-214БВ-25. Вариант 3: сортировка целочисленного массива параллельным слиянием.

## Сборка и запуск

Требуются Linux или WSL, GCC, make и POSIX threads:

```sh
make
printf '5\n3 1 2 1 -4\n' | ./merge --threads 4
```

На вход подаются размер массива и затем его элементы типа `int`; результат — `-4 1 1 2 3`. Время сортировки выводится отдельно в stderr. Пустой массив допускается. Значения входных элементов должны помещаться в `int`.

Генерация входных данных и измерение без вывода массива:

```sh
./merge --threads 4 --size 1000000 --pattern random --seed 42 --quiet
```

`--threads` задаёт общее максимальное число потоков, включая главный (1–256, по умолчанию 1). `--size` создаёт массив нужного размера; `--pattern` выбирает `random`, `sorted` или `reverse`, `--seed` — начальное состояние генератора. `--hold` задерживает первый проход на заданное число секунд и предназначен для демонстрации, а не измерения.

На каждом проходе потоки независимо сливают свои отрезки в общий выходной массив. `pthread_join` ожидает окончания всех рабочих потоков перед следующим проходом. На последних проходах рабочих задач и фактических потоков может быть меньше указанного максимума.

## Демонстрация потоков

```sh
./merge --threads 4 --size 10000 --hold 15 --quiet &
pid=$!
ps -T -p "$pid"
wait "$pid"
```

В выводе `ps` будут четыре строки потоков, включая главный. Во время паузы первый проход содержит достаточно независимых задач.
